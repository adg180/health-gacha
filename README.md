# 健康知识抽卡机

一个把健康科普知识做成「抽卡」的小工具：点一下抽一张卡片，卡片分 R / SR / SSR 三档稀有度。

## 怎么玩

双击 `index.html` 用浏览器打开，点「抽一张」。

## 规则

- 档位权重 **R 70% / SR 25% / SSR 5%**（抽 13 张得到 R 11、SR 1、SSR 1，符合设定）
- 卡片按档位着色：R 灰、SR 蓝、SSR 金
- 页面下方实时显示「已抽 N 张，其中 SSR M 张」

## 我用到的技术

| 层 | 用什么 | 干什么 |
|---|---|---|
| 结构 | HTML | 标题、按钮、卡片容器 |
| 长相 | CSS | 三档背景色、圆角、内边距、居中 |
| 逻辑 | JavaScript | `Math.random()` 按权重抽档位、累加计数、渲染卡片 |

## 我学到什么

- 数据决定长相：`rank.toLowerCase()` 把 `SSR` 变成 `ssr`，正好对上 CSS 的 `.ssr`
- 累加器：Python 是 `total += 1`，JS 要用 `let total = 0`（`const` 不能改）
- 权重抽卡：`Math.random() * 100` 落在 `0–70` 出 R、`70–95` 出 SR、`95–100` 出 SSR
- 终端里粘贴命令前先看提示符：`PS D:\...>` 才是命令行，`> ` 是程序在等输入
